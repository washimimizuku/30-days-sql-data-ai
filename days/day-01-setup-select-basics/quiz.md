# Day 1 Quiz: SELECT Basics

1. **What does SELECT * do?**
   - A) Deletes all rows
   - B) Selects all columns
   - C) Selects all tables
   - D) Creates a table

2. **What is the WHERE clause used for?**
   - A) Sorting results
   - B) Filtering rows
   - C) Joining tables
   - D) Creating columns

3. **What does AS do in SQL?**
   - A) Creates a table
   - B) Creates an alias
   - C) Deletes data
   - D) Sorts data

4. **Which is the correct syntax?**
   - A) `SELECT name, salary FROM employees`
   - B) `FROM employees SELECT name, salary`
   - C) `SELECT FROM employees name, salary`
   - D) `name, salary SELECT FROM employees`

5. **Can you use multiple conditions in WHERE?**
   - A) No, only one condition
   - B) Yes, with AND/OR
   - C) Only with JOIN
   - D) Only in subqueries

**Answers:** 1-B, 2-B, 3-B, 4-A, 5-B
